## Notes

Translated from the ngspice model files of `libraries/ihp_sg13g2`
(`ihp-sg13g2/libs.tech/ngspice/models`) by the netlist converter that ships with VACASK
0.3.4 (`ng2vclib`), with the configuration of its `sg13g2tovc.py`. The models are PSP103
(`psp103va`, `pspnqs103va`): a netlist loads both as OSDI, compiled from the Verilog-A
sources of `libraries/ihp_sg13g2`, and states `parameters swsoa=0`, which the model
cards read.

Generated by `python -m circref build`. Do not edit by hand.
