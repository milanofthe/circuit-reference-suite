## Notes

Translated from the ngspice model files of `libraries/ihp_sg13g2`
(`ihp-sg13g2/libs.tech/ngspice/models`) by the netlist converter that ships with VACASK
0.3.4 (`ng2vclib`), with the configuration of its `sg13g2tovc.py`. A netlist includes
`models/sg13g2_vacask_common.lib` and the section of a corner file. The common file loads
the device modules (PSP103 as `psp103va` and `pspnqs103va`, MOSVAR) as OSDI, compiled from
the Verilog-A sources of `libraries/ihp_sg13g2`, and states what the model cards read
besides: `swsoa` and the default models of the passive elements.

Generated by `python -m circref build`. Do not edit by hand.
