## Notes

Five current-starved inverters and an output inverter. A current pulse into the first stage starts the oscillation; the control voltage steps from 0.7 V to 0.9 V at 40 ns.
The operating point is the unstable equilibrium of the ring; the current pulse sets the start of the oscillation, so that it does not depend on numerical noise.
Written for this suite on the IHP SG13G2 open PDK (PSP103 through OSDI, typical corner), in ngspice's and in VACASK's syntax.
